# Modelo de finiquito

Coloca en esta carpeta el archivo modelo del finiquito que debe reproducir el sistema.

Formatos recomendados: PDF o DOCX.

Nombre sugerido: `modelo_finiquito.pdf` o `modelo_finiquito.docx`.

El modelo se usara para implementar en Contratos las acciones separadas:
- Generar finiquito.
- Subir finiquito firmado.
- Reemplazar finiquito.
- Descargar finiquito.
